# 卡牌生存：无限愿景摘要

本文件只保留当前框架重构需要读取的产品约束；旧草案不作为 active 项目事实，追溯以 git 历史为准。

## 入口边界

- 本文是 CardLoop 自有产品愿景和架构压力源，不是来源项目知识库、任务卡或最终数值设计。
- 当前开发主线仍是文档结构、框架分层和 CardLoop 自有 Gameplay 地基；不得因为本文提到职业、教程、局外空间、联机、Mod 或剧本池就提前实现原创业务。
- 详细剧本、教程、职业谱系、数值候选、UI 草案、视觉参考和 Mod 参考不在 active 文档维护；进入实现前必须另写当前用户故事或任务卡。
- 任何实现拆分都必须继续遵守 [`../../standards/framework-layering.md`](../../standards/framework-layering.md)：玩家可见规则归 Gameplay，通用游戏能力归 GameCore，无游戏语义原语归 YokiFrame。

## 一句话定位

《卡牌生存：无限》是一款以 **卡牌交互 + 小队生存 + 无限流跨世界成长** 为核心的生存管理游戏。

玩家管理自己和一支有性格、有特质、有行动意图的小队，在不同剧本世界里分配行动、处理危机、完成目标，并把职业、技能、经历和部分道具带回局外空间。

## 产品支柱

- **卡牌交互优先**：角色、地点、物品、技能、事件、工位和判定都优先通过卡牌、节点和行动表达，不为战斗、解密、管理分别建立互不相通的交互框架。
- **小队角色独立**：角色有独立性格、特质、意图、关系和可控性；玩家通过操控、协助、领袖、交涉或强制方式影响不同角色。
- **多世界模块化**：每个世界可拥有独立规则、资源、职业、敌人、事件、属性集合和通关目标；属性与规则不得写死成单一世界模型。
- **局外长期成长**：职业、技能、熟练度、经历和部分道具是跨世界积累资源；局内成长不默认从零开始。
- **作者扩展友好**：未来剧本、规则包、职业包、道具包、地图包和 UI 包应走稳定内容 ID、受控扩展点和可验证加载顺序。

## 主循环

1. 局外准备：查看角色、职业、技能、道具、变异和可进入剧本，消耗有限资源选择出发配置。
2. 入局开场：生成初始资源、地点、工位、危机和队伍关系，玩家开始第一轮行动分配。
3. 日常回合：查看天气、士气、饥饿、危机和资源，把角色拖到地点、工位、事件或卡牌上，确认计划并推进回合。
4. 中局扩张：探索解锁蓝图，收集材料，建设设施，在生存压力和扩张收益之间取舍。
5. 危机与战斗：危机以可交互节点出现；战斗始终即时推进，重点是资源、位置、技能组合和后果，不追求过重模拟。
6. 终局结算：完成阶段目标和终极目标后，结算积分、经历、职业进度、可带出道具和剧情结果。

## 首个可玩样例

荒岛生存是首个可拆 MVP 样例，用来验证卡牌生存主循环，不代表全部游戏内容已经进入实现范围。

- 阶段目标：先建造营地；终极目标：建造木筏并逃离海岛。
- 生存压力：每日食物、士气、天气、危机和敌对资源持续影响队伍状态。
- 工位结构：沙滩、森林、海洋、营地、危机节点和天气节点分别承载固定工位、可移动工位或全局交互。
- 探索收益：资源、蓝图、事件和隐藏奖励都通过地点或节点行动产出。
- 队伍差异：玩家、普通队友、厨师、猎人等角色用职业、特质和控制权差异体现小队管理。

## 架构约束

- 玩家可见交互必须回到卡牌、节点、工位、行动、判定和表现反馈；不得额外创建独立的战斗 UI、解密 UI 或管理 UI 真相。
- 普通行动作者只配置消耗回合数；当前世界规则负责声明一个回合换算多少游戏秒。普通行动切换即时推进时复用同一份回合进度，不再维护第二套秒数耗时字段。
- 战斗始终即时制；普通行动的回合 / 即时模式切换不能改变攻击、技能时间轴和冷却的实时推进。
- 固定工位数量只表示可同时承载多少次独立行动；同一次行动可以有多名参与者。参与者越多默认缩短耗时，成功判定默认取相关等级最高者，不给每名参与者独立重掷。
- 同一角色当前只能属于一个工位行动；该事实必须由工位分配状态的唯一写入口保证，不能增加预留表、锁表或防重影子状态。
- 活动战斗不保存攻击进度、技能时间轴、临时效果、随机流或战斗参与状态；存档重点是局外成长和后续明确选择保留的非战斗状态。
- “符号”是策划语言；正式实现时映射为 EX-GAS GameplayTag 的匹配标签或查询，不另建与 GAS 并行的 string 符号系统。
- 未来 Mod / 剧本体系按“一个活动剧本 + 多个插件包”理解，插件只能通过受控挂载点改变规则、内容、地图、UI 或脚本行为。

## 后续拆解顺序

以下只是设计拆解顺序，不代表当前开发切换到原创业务实现：

1. 锁定荒岛生存第一局最小可玩闭环。
2. 拆初始地图、角色卡、资源卡、事件卡和工位。
3. 拆新手教程的最短基础交互流程。
4. 拆 UI 原型：中央桌面、下方回合推进、右侧角色详情、卡牌快捷操作和悬浮详情。
5. 再拆局外空间、职业谱系、跨局成长、Mod、联机和跑团工具。
