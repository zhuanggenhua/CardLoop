# 卡牌生存：无限

## 记录状态

- 本文以用户 2026-08-06 当前对话提交的完整设计稿为正式版本；后续设计继续在此版本上增量订正。
- 当前版本目标：按“玩家从局外准备到局内生存，再到成长带出”的流程整理；表格基本撤掉，案例不再单独抬成系统章节。
- 早期口述、视觉参考图和 Mod 参考记录只有已经合并到本文的内容才视为有效项目知识；未合并内容不再作为正式事实入口。
- 本文是项目愿景草案和架构扩展性约束，不是任务卡，也不是最终数值设计。
- 当前开发主线仍是 GamePlay 地基与 StackCraft 模板能力吸收；不得因为本文记录了职业、教程、战斗、局外空间或剧本池，就提前实现原创业务内容。

## 一句话定位

这是一款以 **卡牌交互 + 小队生存 + 无限流跨世界成长** 为核心的生存管理游戏。

玩家不是单独扮演一个工具人，而是管理自己和一支有性格、有特质、有行动意图的小队，在不同剧本世界里分配行动、处理危机、完成目标，并把职业、技能、经历和部分道具带回局外主神空间。

## 核心参考

- 《堆叠大陆》：卡牌化资源、地点、角色和行动。
- 《鲁滨逊漂流记》《死亡寒冬》：合作生存、资源压力、团队危机。
- 《密教模拟器》：圆形节点、可移动工位和仪式感交互。
- 《漫野奇谭》：角色经历、右侧角色详情卡和轻叙事。
- 《Kenshi》：独立角色、小队沙盒和个体差异。
- 《迷域行者》：性格、特质和小说式剧情场景。
- 《皇家骑士团》：转职、职业经验保留和职业谱系。
- 《太吾绘卷》：轻量化战斗参考。
- 《诡镇奇谈》：点对点路径移动和区域事件。
- 《苏丹的游戏》：卡牌填充式弹窗交互。
- 《大巴扎》：列为候选学习对象，具体可吸收机制仍需后续单独拆解，不预设结论。

玩法内容需要同时覆盖战斗、解密和管理，但三者都应服从卡牌交互与小队生存主循环，不能各自发展成彼此隔离的第二套游戏。

## 核心设计支柱

### 卡牌交互优先

- 核心不是“把东西堆起来”，而是用卡牌和节点承载角色、地点、物品、技能、事件、工位和判定。
- 物品、武器、技能都可以拖拽触发交互判定。
- 多选项交互可以在卡牌侧边弹出操作按钮。
- 任意卡牌都可以在特殊规则下临时作为交互地点使用。
- UI 不应该复杂到破坏卡牌本身的可读性。
- 战斗、解密和管理都通过卡牌、节点、工位、技能和判定组合表达，而不是为每类玩法建立互不相通的交互框架。

### 多世界模块化

- 每个世界可以有独立规则、资源、职业、敌人、事件和通关目标。
- 玩家通过局外购置职业、道具、变异、技能来适配不同世界。
- 主神空间本身也是模块化可替换设计，外观和规则由“诸天管理者”的业绩决定。
- 游戏天然适合 Mod，也可以扩展成跑团工具。
- 世界可以扩展基础属性集合，例如修仙世界增加灵根；规则和 UI 必须读取当前世界装配的属性，而不是把 DND 六维写死为全部世界的固定上限。

### 小队角色是独立个体

- 所有角色都有独立性格、特质、AI 逻辑和对话表现。
- 性格影响角色意图、拒绝行动、投票倾向和对话反馈。
- 特质是常驻被动效果，采用轻量标签化设计。
- 舍弃《漫野奇谭》复杂个性系统，避免模拟过重。

### 局外长期成长

- 角色所有对局经历都会被记录，并影响属性和能力。
- 对局内获得的能力、道具如果要带出对局，需要消耗对应积分。
- 职业、技能、熟练度、经历是跨世界积累的核心成长资源。
- 玩家以“魂穿诸天”为核心设定，不需要每个剧本从零养成。

## 完整游戏流程

### 局外准备

1. 玩家进入主神空间。
2. 玩家查看已有角色、职业、技能、道具、变异和可进入剧本。
3. 玩家消耗有限积分购置职业与道具。
4. 玩家选择剧本世界，例如鲁滨逊漂流记式荒岛生存。
5. 系统根据剧本规则生成随机目标、随机地图和初始事件。

### 入局开场

1. 玩家角色和队友进入剧本。
2. 游戏生成初始资源、初始地点、初始工位和初始危机。
3. 玩家查看队伍角色：自己可以直接操控；友好单位可以操控或协助；陌生人需要通过领袖、好感、交涉或强制方式影响；联机模式下可能存在叛徒。
4. 玩家开始第一天行动分配。

### 日常回合循环

荒岛样例和普通牌桌行动默认采用回合制；战斗始终采用即时制。普通行动允许由剧本 / 世界规则切换为即时推进，但行动作者只配置消耗回合数；当前生效的回合时间规则统一声明“一个回合对应多少游戏秒”，即时制据此换算同一份回合进度，不允许行动再维护持续秒数。

1. 玩家查看当前天气、士气、饥饿、危机和资源。
2. 玩家把角色拖到地点、工位、事件或卡牌上。
3. 系统根据角色属性、职业技能、道具和地点规则生成可执行操作。
4. 玩家确认行动计划。
5. 点击下方居中的日月时间标记，推进回合。
6. 系统按玩家顺位依次结算行动。
7. 行动结算时触发属性检定，表现参考《博德之门》的掷骰动画。
8. 检定结果悬浮展示在角色或交互节点上方。
9. 回合结束后刷新事件、危机、天气后果、敌人意图和资源变化。

### 时间推进实施用户故事

- 作为玩家，我希望行动能按可见秒数推进，并能获得明确的开始、进行中、暂停、恢复、取消和完成反馈。
- 作为剧本或 Mod 作者，我只配置普通行动消耗多少回合，不需要再为即时制手填一份秒数耗时。
- 作为剧本或 Mod 作者，我可以在回合规则中配置一个回合对应多少游戏秒；普通行动切换即时制后按照该规则换算，行动内容和作业不产生第二耗时真相。
- 作为玩家，我希望普通行动默认等待回合确认推进；剧本切换到即时制后，当前作业从已有回合进度继续，不重置也不重新换算存量数据。
- 作为玩家，我希望战斗始终保持即时制；普通行动的回合 / 即时模式切换不能改变战斗攻击、技能时间轴和冷却的实时推进。
- 作为开发者，我需要统一测试“默认回合制不随现实时间推进 -> 正式推进一回合 -> 切换即时制继续同一份回合进度 -> 暂停、倍速、恢复、完成和取消”，并禁止 `DurationSeconds` 这类行动秒数作者字段重新出现。
- 世界当前回合、回合确认、日结阶段和 EX-GAS 回合推进仍由后续正式世界流程 owner 统一编排；行动作业系统只消费已确认的回合事实，不保存第二份全局回合计数。

### 中局扩张

1. 玩家通过探索、空行动智力检定、事件奖励等方式解锁蓝图。
2. 玩家收集材料并把材料、角色放入蓝图工位。
3. 蓝图建造完成后替换成实体设施。
4. 设施解锁新的工位、升级路径和长期收益。
5. 玩家开始在“生存压力”和“扩张收益”之间做取舍。

### 危机与战斗

1. 危机事件以圆形交互节点形式出现。
2. 长期放任危机会触发负面卡牌效果。
3. 野兽等敌对资源长期不处理，也会触发回合负面效果。
4. 玩家可以通过战斗、交谈、技能、道具或特殊工位处理危机。
5. 战斗系统设有前后排站位，提供基础战术搭配。
6. 战斗不追求高复杂度，重点放在资源、位置、技能组合和后果。

### 终局逃脱

1. 玩家完成阶段目标后进入终局准备。
2. 终局通常需要高消耗建造或高难事件处理。
3. 荒岛样例里的终极目标是建造木筏。
4. 玩家完成目标后结算积分、经历、职业进度、道具带出和剧情结果。

## 荒岛生存剧本样例

### 开局目标

- 阶段目标：建造营地，需要木头数量 = 玩家人数 × 1，需要树叶数量 = 玩家人数 × 1。
- 终极目标：建造木筏并逃离海岛，需要木头数量 = 玩家人数 × 4。

### 剧本专属规则

- **饥饿机制**：角色每日需要进食 1 单位食物，未进食则扣除 10% 生命值，数值向上取整。
- **士气机制**：士气为负时，回合结束触发随机负面状态；对局经历大于等于 3 倍关卡等级的角色可免疫；士气为负时，所有技能释放需要额外消耗士气。
- **建造限制**：只能建造已经解锁蓝图的道具与设施；未解锁蓝图时，即使材料足够也不能建造。
- **时间机制**：单天分为两个行动回合；每日过夜时随机刷新天气。
- **空行动收益**：未分配工位的角色可以进行智力检定；检定通过后随机解锁新蓝图。
- **队长权限**：房主或玩家默认担任队长；资源短缺时，队长可以优先分配生存资源。

### 地图与工位

- 中下区域是初始营地蓝图，标注建造材料与工位；填满材料并放置角色完成建造后，蓝图替换为实体营地，并解锁升级工位。
- 营地是可移动圆形交互物，提供无限休息工位，并承担后续升级和恢复功能。
- 沙滩有两个固定交互工位，默认用于探索或采集。
- 左上、右上、上方是森林固定工位，默认交互是探索；持有喷火器可解锁焚烧交互；放置狩猎技能可以触发狩猎行为。
- 森林探索可随机刷新浆果、树木、野兽资源；野兽长期不处理会触发回合负面效果。
- 右下海洋区域是专属采集工位，可安排角色采集食物；鱼竿属于背包道具，不属于武器。
- 工位不限制参与人数。多个角色进入同一工位时，属于同一次行动的共同参与者，不是对同一地点并行创建多次行动，也不是通过共享/独占开关绕过容量。
- 固定工位数量只表示同一时间可以承载多少次独立行动：例如沙滩的两个固定工位可以同时运行两次行动，但每次行动都可以有任意数量角色参与；营地的无限休息工位表示可以按需创建任意数量独立休息行动。
- 同一角色当前只能属于一个工位行动，这应由工位分配状态的唯一写入口保证，不能额外维护预留表、锁表或防重影子状态。内部代码若形成重复归属，必须立即报出不变量错误；联机客户端提交的过期分配指令由权威端作为状态已变化正常拒绝。
- 多人参与的结算策略允许行动和 Mod 自定义。当前默认规则是参与者增加会缩短行动耗时，但成功判定只使用相关判定等级最高的参与者，不因人数增加而默认获得多次独立重掷。
- 危机事件是圆形交互节点，长期放任会触发负面卡牌效果。
- 天气是全局可交互机制；恶劣天气会降低栅栏等级与耐久，晴天娃娃可以抵消天气负面效果。

### 初始队伍

- 玩家：探索者。探索时降低负面事件概率，50% 概率额外获取探索卡牌。
- 无用之人：无专属特质，作为普通队友承接基础教学。
- 厨师：开局解锁全部食谱，拥有专属烹饪特质。
- 猎人：对野兽伤害 +20%，食物采集收益翻倍，初始解锁解剖技能。

### 首回合示例

1. 玩家分配行动：玩家探索森林，甲、乙探索沙滩，丙探索上方森林。
2. 系统提示探索次数越多，事件与危机触发概率越高。
3. 首回合结算：玩家获取大树、树叶；丙获取树叶；甲、乙获取石头、可燃垃圾；可燃垃圾可作为燃料使用。
4. 二次探索触发特殊事件：难度 1 敏捷检定，需求 10 点；检定失败仍正常获取资源，但触发【隐秘的坡道】。
5. 【隐秘的坡道】未处理则回合结束受到 1 点物理伤害；敏捷检定 12 点可处理事件，16 点可触发隐藏奖励并解锁埋藏宝箱。

## 新手教程流程

教程目标是用最短流程覆盖全部基础交互和职业系统玩法，同时允许玩家用道具快速自杀重置教程。

### 捏人开场

- 玩家开局处于失忆状态，初始无法选择职业，只能完成基础捏人。
- 可设置性别、形象、基础属性加点；全部操作都在右侧角色信息面板完成，不需要切换界面。
- 性格特质是隐藏被动属性，需要专属技能解锁查看；通过对话判别角色性格，是后续核心玩法之一。
- 玩家默认以「无用之人」开局；可选现代背景包括作家、伐木工、警察等。
- 玩家自定义模块未来可影响 NPC 基础属性，但暂不优先开发，只作为角色卡设计参考。

### 队伍领袖规则

- 玩家完成事件、协助队友可积累领袖值。
- 无倾向陌生人会投票选举领袖值最高者为队长。
- 领袖可以强制指派队友行动。
- 队友拒绝执行会降低全队好感。
- 友好单位和叛逆特质单位可免疫该好感惩罚。

### 教程主流程

- **高难度开局**：玩家与 5 名失忆陌生人在荒岛苏醒，全员互不信任，教程目标是存活 10 天。
- **友好 NPC 登场**：唯一友好 NPC 警察登场并主动带队；系统提示玩家只能操控自身与友好单位。
- **教学世界核心规则**：队长可以指挥陌生人行动；非领袖角色必须执行队长分配任务；拒绝执行会降低全队好感。
- **教学投票交互**：临时刷新圆形投票按钮，点击后弹出投票窗口；陌生人自主投票，得票最高者获得队长 Buff，图标显示在卡牌左上角内侧；该交互可通过关卡编辑器自由配置。
- **触发剧情冲突**：有犯罪记录的陌生人拒绝警察管辖并发起武力争夺队长权限，同步教学 NPC 意图卡牌交互规则。
- **区分角色类型**：剧本原生 NPC 的卡牌顶部显示行动意图，回合结束统一结算；普通玩家角色通过拖拽卡牌完成行动；真实玩家角色由真人手动操控。
- **教学队长争夺工位**：队长争夺是专属工位交互，拖拽角色到工位后触发力量检定；普通对战胜利可以抢夺物资或击杀目标，但会大幅降低全队好感。
- **教学意图结算**：所有角色意图不会即时触发，玩家确认结束回合后系统统一执行。
- **抉择分支**：玩家可以袖手旁观、交涉或主动交互目标角色。
- **角色基础交互**：拖拽角色后弹出交谈、陪伴、战斗、取消四类选项；角色交互不占用回合，陪伴可以清除目标心理负面状态。
- **交谈进阶判定**：安抚可取消目标当前意图；教唆可临时操控目标一回合；威胁可强制操控角色行动但风险更高，高难度威胁可以同时要求力量与敏捷等多个属性鉴定；索要可向目标角色申请获取物资。
- **战斗教学**：残血角色会触发逃跑敏捷对抗检定；逃跑成功则暂时离场，后续大概率回归并提升对局难度；开战瞬间双方变为敌对，敌方友好单位会自动参战，特殊场景除外。
- **剧情推进**：玩家通过安抚成功平息冲突，警察好感提升，全队开始有序开展生存行动。
- **陷阱教学**：角色探索树林触发即时陷阱【捕熊夹】，剧情上高难度敏捷检定必定失败，角色获得【残疾】状态并受到 2 点伤害。
- **残疾状态示例**：无法装备鞋子；无法自主移动，需要其他角色「背起」后移动；近战命中率降低 50%；双人同工位时可以共享工位；投掷、采集判定取最高值；协同行动提升角色好感，相似特质角色增益更高。
- **道具与职业技能**：绷带可治愈失血状态；医生被动可保证绷带治疗必定成功；警察 NPC 展示威慑、擒拿术、载具驾驶、枪械精通一级等职业能力。
- **职业经验提示**：维护秩序、打击犯罪和帮助他人，都会增加警察职业经验。
- **教程收尾**：玩家调查陷阱脚印，解锁支线任务；完成支线可获得额外积分；同步讲解角色属性、记忆槽、技能槽、被动槽基础机制。

## UI 与交互设计

### 总体布局

- 中央区域是主桌面，承载地图、地点、事件、可拖拽卡牌和主要交互工位；采用开放式桌面，不使用厚重边框把区域围死。
- 屏幕下方居中是日月时间标记，同时承担回合推进和计划确认，不应该和手牌区域抢空间。
- 右侧是详情面板，选中角色后展开，通过 Tab 展示装备、技能、详细属性和对局经历，参考《漫野奇谭》的右侧角色卡。
- 卡牌侧边用于快捷操作，只显示当前可用动作，不常驻大段解释文字。
- 悬浮信息用于临时详情；物品卡展示属性与关卡规则，角色卡展示 DND 六维属性、背景、职业等基础信息。

### 卡面信息

- 顶部显示角色名称，右侧显示职业徽记。
- 角色卡主视觉采用抽象背影风格。
- 左下角展示攻击类型与攻击伤害数值，右下角展示血量进度条。
- 护盾优先消耗，护盾存续期间隐藏血量，详细数值在右侧详情面板查看。
- 血量上方显示职业专属资源条，例如法力、灵气等，不同资源用图标差异化区分。
- Buff 效果竖向悬浮展示在卡牌左侧外侧，不压住卡面主视觉。

### 卡牌交互

- 悬浮卡牌时，右下角弹出详情面板。
- 点击选中角色时，右侧展开侧边角色卡，Tab 分页展示装备、技能、详细属性、对局经历。
- 选中角色后，可用技能显示在屏幕下方而不是角色侧边，避免遮挡桌面与卡牌。
- 技能可以手动释放、拖拽交互，也可以拖拽学习。
- 固定装备槽包括头部、躯干、左手、右手、脚部。
- 肢体系统独立于血量体系，用于模拟生存状态和角色变异；部分变异状态仍可正常穿戴装备。
- 战斗牌桌允许扩展为多排站位，当前至少需要支持前排与后排。

### 地点交互形态

- **固定工位**：场景固定贴图，提供固定交互工位，适合沙滩、森林、海洋等玩法固定区域。
- **可移动圆形工位**：对标《密教模拟器》，点击后弹出详情弹窗与交互工位；拖拽角色可触发快捷交互；危机、天气事件都采用该形态。
- **连通性节点**：用于跨区域联动交互，当前仍处于构想阶段。
- **卡牌工位**：任意卡牌都可以临时作为交互地点使用，用于事件、剧情、道具或特殊规则。

## 局外主神空间

- 主神空间是玩家的局外主城，提供固定即时交互点位。
- 玩家可以在这里购置剧本道具，也可以解锁角色变异。
- 主神空间规则和外观都可以模块化替换。

### 变异规则

- 变异遵循单部位单变异规则。
- 强力变异会附带高额负面效果。
- 变异设定对标《无限恐怖》的血统设定。

### 吸血鬼变异示例

- 吸血鬼需要定期吸血；断供一次会持续虚弱，再次断供会直接死亡。
- 吸血操作消耗两名角色的单回合行动。
- 吸血会大幅降低人类角色好感。

## 职业系统

### 职业升级

- 职业等级只能通过完成对应职业专属行为提升。
- 等级提升后获得固定属性加成。
- 升级时三选一习得新技能，这种随机选择用于保障重复游玩变化。
- 角色属性由基础属性 + 职业属性共同组成。

### 技能与转职

- 游戏遵循 DND 数值规则，支持转职，禁止兼职。
- 转职只清空当前职业等级经验；过往职业经验、对局经历全部保留。
- 普通职业主动技能、被动技能和技能熟练度永久保留。
- 只有剧本专属剧情技能会在转职后失效。
- 职业转职逻辑参考《皇家骑士团》。

### 职业谱系

- 上下级职业可以多路径互通。
- 上级职业继承下级职业等级，同时受限于下级等级上限，避免职业强度溢出。

### 等级作用

- 职业等级决定角色属性上限和可携带技能等级。
- 后期可使用遗忘药水清空职业等级并保留全部技能，也可以通过拜师、带新人学习缺失技能。

### 等级梯度

- 1 级：对应普通人十年深耕经验。
- 低魔职业上限 5 级：人类半生职业极限。
- 中魔职业上限 10 级：人类能力极限。
- 高魔职业上限 20 级：超凡层级，突破人类范畴。

### 快速升级逻辑

玩家是魂穿附身状态。剧本升级获取的是附身角色的积累经验，不需要从零养成，因此对局内升级速度可以更快。跨世界积累的经验是核心成长资源。

### 特殊职业：无用之人

- 无用之人没有固定职业体系，主打自我探索。
- 10 级解锁基因锁，开放额外能力槽。
- 魔法装备可以部分替代基因锁能力槽，所以不需要刻意拉高等级。

## 数值体系

- 基础数值从 DND 六维体系出发，但会进行迭代改造和简化，并支持 Mod 改造为 COC 数值模式。
- 判定系统需要支持多个属性同时鉴定，满足 COC 式复合条件和高难度交互。
- 属性集合允许由世界或 Mod 扩展，例如修仙世界增加灵根，不能把所有属性写死为单一枚举。
- 抗性采用离散等级表达的候选规则：穿刺抗性每高一级，减少 25% 带有穿刺属性的伤害；具体上限与叠加顺序尚待战斗模块确认。
- 存在隐藏属性“幸运”，可提升正向事件触发概率，并小幅降低对局整体难度。
- 技能消耗不固定，可使用法力、SAN 值、灵能等资源。
- 感知属性可以提升灵能上限。
- SAN、法力、灵能属于不同职业或世界体系的特有属性与资源，表达方向参考《Tales of Maj'Eyal 4》，不要求所有角色同时拥有。
- 技能冷却跨度极大，可能是秒级、回合、天数或单局冷却。

## 设计风险与约束

- 不适合模拟高复杂度战斗体系；深度应放在资源、位置、状态、技能组合和后果上。
- 不适合搭配复杂 UI；信息应优先分散到卡面、侧栏、悬浮层和流程节点。
- 纯卡牌交互代入感较弱，需要依靠文本叙事、事件插画和角色经历补足沉浸感。
- 自由拖拽难以精准表达空间距离，应使用固定工位、连通节点、地点标签补充空间层级。

## 扩展案例

- **机甲工位**：放置角色激活机甲作战单元，解锁专属机甲战斗形态。
- **喷火器交互**：对相邻最多三个单位造成火焰魔法伤害，解锁木质卡牌专属焚烧判定交互。
- **即时敌人机制**：部分敌人登场即刻触发交战；玩家可强制移走目标规避，但会触发借机攻击；眩晕状态可以免疫借机攻击。
- **无用之人专属机制**：10 级解锁基因锁，拓展能力槽；魔法装备可以弥补潜能上限短板。
- **火焰跳跃能力**：复刻《诡秘之主》玩法，可无视借机攻击，优先攻击着火单位，并触发场景文字提示。
- **潜行隐匿机制**：角色进入藏身处工位，可规避敌对单位优先锁定。
- **特质自定义**：小个子特质可模拟矮人形态，并适配专属场景交互。
- **战斗外能力**：部分战斗能力无需进入正式战斗即可使用，例如超远距离攻击；也允许能力移动敌方卡牌形成连携。
- **状态影响交互**：交互候选和结果会读取角色当前状态，例如隐身状态可以解锁或改变特定交互。
- **战术家换位**：战术类能力可以交换前后排单位，并允许在满足规则时移动到指定战斗位置。
- **幸运一击 / 幸运币**：幸运资源可以成为特殊攻击或结果分支的输入，具体消耗与概率待后续拆解。
- **大背包组合**：大背包既可强化调查角色的鉴定能力，也可与武斗角色的多武器使用能力组合。
- **油性笔仪式**：普通道具可以绘制仪式法阵；是否成功由知识相关判定决定，失败信息可以保持未知以支持解密体验。

### 多人工位默认规则

- 多个单位参与同一次工位行动时，默认缩短完成所需时间。
- 成功率只按相关判定等级最高的参与者计算，不默认让每名参与者分别重掷。
- 行动、剧本和 Mod 可以覆盖该策略，但必须通过正式规则入口表达，不能用工位人数上限、共享开关或影子状态模拟。

## Mod 参考：部落与弯刀

- 参考入口：`https://blywd.hanjiasongshu.com/mod/`，只作为 Mod 体系设计参考，不作为 CardLoop 事实或实现约束。
- 可参考点：区分“剧本战役”和“插件”；运行时有且仅有一个剧本战役，同时允许加载多个插件。
- 可参考点：插件不能独立运行，而是挂载到剧本或通用剧本之上；适合 CardLoop 的“世界/剧本 + 职业包/规则包/道具包/地图包/UI包”结构。
- 可参考点：插件具备加载顺序，后加载插件可覆盖前加载内容；插件可以声明依赖，系统在启动时自动修正加载顺序。
- 可参考点：开发环境分简易和专业两类，覆盖配置表、资源、技能、地图、脚本、打包、测试和 Steam 创意工坊发布。
- 可参考点：编辑器嵌入游戏本体，可从游戏主菜单进入 Mod 开发，支持新建/打开项目、构建、上传、调试和日志查看。
- 可参考点：脚本扩展通过受控挂载点运行，例如进入游戏、时间 tick、查询函数、UI patch；CardLoop 后续 API 也应优先提供受控扩展点，而不是允许任意代码直接改核心状态。
- 可参考点：地图编辑器使用绑定类型和对象 ID 把地图图块绑定到地点、触发器、障碍或碰撞区域；CardLoop 的关卡编辑器也应通过稳定内容 ID 绑定地点、事件、规则和牌桌初始对象。
