# Verification Before Completion（完成前验证）

## 铁律

没有新鲜验证证据，不得声称完成、修好或通过。

## 验证步骤

1. 识别：哪条命令、测试、截图、Unity 状态、数据记录或文档链接能证明本轮目标？
2. 执行：运行完整验证或读取真实证据。
3. 阅读：看退出码、失败数、关键输出、目标结果，不只看“无报错”。
4. 声明：只按证据说话；未覆盖的地方列 known gaps。

## 不足以证明完成

- “应该可以”。
- “日志没了”。
- “子 agent 说成功”。
- “只跑了局部命令却声称全量通过”。
- “修了相邻问题，但没回到用户原始症状”。

## 文档/规范任务验收

- 根入口能指向 `.spec`。
- `.spec/knowledge/README.md` 能导航到相关内容。
- 新增 skill frontmatter 合规。
- 链接路径存在。
- 未删除或覆盖旧规则语义。
